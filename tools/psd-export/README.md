# Gifts for Her — layered PSD export

`gifts-for-her.psd` is an editable rebuild of the "Gifts for Her" email design,
generated by the scripts in this directory.

## What "editable" means here

The source artwork was a flat raster image, and flattened pixels cannot be
un-flattened — there is no way to recover the original text objects or the
photography from a JPEG. So the design was **re-authored** rather than traced:
every element is a real object again.

| Element | How it exists in the PSD |
| --- | --- |
| All copy (32 items) | Live **type layers** — click with the Type tool and retype |
| Bands, cards, pills, circles | Individual raster shape layers, one per element |
| Photography (5 slots) | Empty, named **photo slots** — see below |

Layers are grouped by section (`01 - Header` … `06 - Footer`) so each block can
be moved, hidden, or restyled on its own.

## Canvas

1200 × 5100 px at 72 DPI — a 600 px email column at 2× density. At 72 DPI points
and pixels are 1:1, so a type layer set to 42 pt measures 42 px.

## Fonts

Type layers reference **Montserrat** (display) and **Inter** (body). Both are
free from Google Fonts. Install them before opening, or Photoshop will flag
missing fonts and substitute — the text stays editable either way.

These are stand-ins chosen to match the original's proportions. If you know the
brand typeface, swap the constants in `build_psd.py` and regenerate.

## Dropping in the real photos

Each slot is a group named `PHOTO SLOT - <name>` containing:

- `Tint Base (clip your photo to this)` — a rounded colour block
- `Placeholder Guide (delete once filled)` — dashed outline and hint text

To fill one:

1. Delete the `Placeholder Guide` sub-group.
2. Paste your photo directly **above** `Tint Base`, inside the same group.
3. `Alt`/`Option`-click the line between them to clip the photo to the rounded
   corners.

## Regenerating

```sh
pip install -r requirements.txt
python3 build_psd.py gifts-for-her.psd
```

Writes the PSD plus `gifts-for-her-preview.png`.

## Files

- `build_psd.py` — layout, palette and copy for this design
- `psdlib.py` — minimal layered-PSD writer (groups, raster layers, type layers)
- `textengine.py` — builds the Photoshop text-engine blob that keeps text live
- `verify_psd.py` — re-opens the output and checks it parses

## Verification

`verify_psd.py` confirms, on the written file, that: the canvas is correct;
every type layer round-trips with its text, font, size, tracking and fill;
and compositing the stored layer data reproduces the renderer's output exactly.

It was additionally parsed with ImageMagick — an independent PSD
implementation — which reads all 65 layers with correct names and bounds.

Note that no copy of Photoshop was available in the build environment, so the
file has not been opened in Photoshop itself.
